# Language Translator

## 📌 About the Project

This is a simple Language Translator application built using Python and Tkinter. It allows users to enter text, select a source language and a target language, and translate the text into the selected language.

The application uses the LibreTranslate API to perform the translations.

##  Features

- Translate text between different languages
- Simple and user-friendly graphical interface
- Source and target language selection
- Swap source and target languages
- Clear and easy-to-use design

##  Technologies Used

- Python
- Tkinter
- Requests
- LibreTranslate API

##  Supported Languages

The application supports:

- English
- Urdu
- Arabic
- Turkish
- Hindi
- French
- Spanish
- German
